# Kora launch kit

## Positioning

Kora: a free, open-source alternative to IDM for Windows.

## Tagline

Free to download. Open to improve.

## Repository description

Free, open-source Windows download manager with resumable files, supported video links, quality selection and batch downloads. Preview release. YouTube excluded.

## Launch post

Meet Kora, a free, open-source alternative to IDM for Windows.

Download files, queue supported video links, choose quality, and pick up eligible
downloads where you left off. Kora also includes batch links, automatic names,
dedicated video folders and saved preferences.

No payment or activation key is required. This first public version is a preview,
and I'd love help testing it and improving it.

YouTube is excluded, site support varies, and DRM-protected media is unsupported.
Setup downloads the runtime and video tools when needed.

Find the download and source at:
https://github.com/omsc1213/kora-download-manager

## Short caption

Kora is here: a free, open-source alternative to IDM for Windows. Resumable files,
supported video links and batch downloads. Try the preview and help improve it.
YouTube excluded. Link in bio.

## Short demo sequence

1. Show Kora and the line "A free alternative to IDM for Windows".
2. Paste a permitted video link and select Find video.
3. Show available quality, generated filename and destination.
4. Add to queue, pause, then resume a supported download.
5. Finish with the repository URL and "Preview release. Help us test it."

## Claims to use

- Free to use; MIT-licensed original source.
- No built-in ads or activation key requirement.
- Parallel file transfers and supported video links.
- Windows preview; community feedback welcome.

## Claims to avoid

- "Downloads from every website", "always fastest" or "faster than IDM".
- "Official IDM", "IDM clone" or an IDM endorsement.
- "100% Rust", "fully tested on every site" or "guaranteed resume".
- "No internet needed for setup" or "all dependencies bundled" for this public ZIP.
- "No setup required" or "Chrome Store extension".

Use Kora's own visual identity. Do not use IDM's logo or screenshots as Kora's UI.
