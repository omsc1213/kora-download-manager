# Contributing

Issues, reproducible bug reports and focused pull requests are welcome.
Use a public sample URL you have permission to share. Remove signed tokens,
cookies, private media URLs, local usernames and account information from logs.

Useful contributions: real-site compatibility reports, pause/restart recovery,
accessibility, Windows installer tests and clearer errors. Keep YouTube excluded
and do not add DRM circumvention. Add meaningful regression coverage for fixes.

Changes to the app and documentation are contributed under the MIT license.
Dependencies keep their original licenses. Do not upload third-party binaries
to the source repository or copy proprietary IDM code, branding or assets.
